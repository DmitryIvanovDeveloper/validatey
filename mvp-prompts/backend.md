## Backend API
- CRUD для проектов, сегментов, гипотез; хранение сгенерированных сценариев и версий после ручного редактирования.
- Эндпоинты рассылки приглашений/напоминаний и приём ответов (включая загрузку аудио), трекинг статусов приглашений.
- Очереди задач: генерация сценария (LLM), рассылка, обработка ответов (транскрипт, эмбеддинги, кластеризация), сборка отчёта.
- Расчёт метрик: острота проблемы (score агрегаты), частоты альтернатив, кластеры цитат, WTP (медиана/перцентили), рекомендация (rule-based + LLM пояснение).
- API отчёта (JSON) + генерация HTML/PDF; защита выдачи по токену проекта/приглашения.
- Логирование/метрики, ограничение rate для публичных форм, базовый антиспам/PII фильтр.
- Привязка к сценарию Анны: шаги регистрации/создания проекта → мастер (сегмент, гипотеза, сценарий, аудитория/стоимость) → запуск/оплата → прогресс (статусы, ранние сигналы) → приём ответов по токену → финальный отчёт/экспорт/шаринг. Обеспечить idempotency и версионность сценариев/отчётов.
