## Frontend (PM Console + Respondent UI)
- Реализовать PM-консоль: создание проекта, ввод сегмента/гипотезы, просмотр/редактирование LLM-сценария, запуск рассылки, статусы приглашений, скачивание отчёта.
- Создать форму респондента (web/mobile-friendly): шкалы 1–5, открытые ответы, опционально аудио; поддержать напоминания по токену ссылки.
- Интегрировать с backend API для сценариев, приглашений, ответов, отчёта (HTML/PDF загрузка/просмотр).
- Добавить базовую аналитика/телеметрию UI: загрузки страниц, начало/завершение опроса, дроп-оффы по шагам.
- Обеспечить защищённый доступ: токен приглашения/письма → доступ к конкретному опросу без регистрации; CSRF/валидаторы форм.
- Экранный чек-лист (Анна): логин/онбординг → пустой дашборд с CTA → мастер 4 шага (сегмент, гипотеза с AI-помощником, сценарий редактируемый, аудитория/цена/оплата) → экран прогресса (статусы, ранние сигналы) → форма респондента с прогресс-баром → отчёт (вердикт, метрики, кластеры, альтернативы, WTP, рекомендации) → экспорт/шаринг → «новый раунд/гипотеза».
