# Validatey - Описание функционала

## Обзор приложения

Validatey - это платформа для валидации продуктовых гипотез через опросы целевой аудитории. Приложение позволяет создавать проекты валидации, генерировать сценарии опросов с помощью AI, собирать ответы респондентов и получать аналитические отчеты.

## Основные страницы и функционал

### 1. Dashboard (Главная страница)
**Путь:** `/`

Главная страница с обзором всех проектов пользователя:
- Карточки проектов с названием, статусом и датой создания
- Кнопка создания нового проекта
- Быстрый переход к деталям проекта
- Пустое состояние для новых пользователей

### 2. Мастер создания проекта (4 шага)

#### Шаг 1: Определение целевого сегмента
- Описание целевой аудитории
- Демографические данные (возраст, локация, профессия, доход, интересы)
- Примеры заполнения на английском языке

#### Шаг 2: Формулировка гипотезы
- Описание продуктовой гипотезы
- Список предположений (assumptions)
- AI-помощник для формулировки гипотезы

#### Шаг 3: Редактирование сценария
- **Автоматическая генерация сценария** с помощью AI на основе сегмента и гипотезы
- **Визуальный режим:** вопросы отображаются в удобных карточках
- **JSON режим:** технический вид для редактирования
- Кнопка регенерации сценария
- Типы вопросов: шкала, открытый текст, множественный выбор

#### Шаг 4: Аудитория и оплата
- Название проекта
- Размер аудитории (рекомендуется 100-200 респондентов)
- Цена за ответ
- Автоматический расчет общей стоимости проекта

### 3. Детали проекта
**Путь:** `/projects/:projectId`

Полная информация о проекте:
- Общая информация (название, статус, даты)
- Описание сегмента и демография
- Гипотеза и предположения
- Сгенерированный сценарий опроса

Навигация:
- Управление приглашениями
- Прогресс проекта
- Отчет по проекту

### 4. Прогресс проекта
**Путь:** `/projects/:projectId/progress`

Метрики и статистика в реальном времени:
- Общее количество приглашений
- Отправлено приглашений
- Получено ответов
- Процент ответов (response rate)
- Статусы приглашений
- Ранние сигналы и тренды

### 5. Отчет по проекту
**Путь:** `/projects/:projectId/report`

Аналитический отчет с результатами валидации:
- **Вердикт:** общий результат валидации (подтверждена/не подтверждена)
- **Ключевые метрики:**
  - Процент ответов
  - Оценка удовлетворенности
  - NPS (Net Promoter Score)
- **Кластерный анализ:** сегментация респондентов
- **Willingness to Pay (WTP):** готовность платить
- **Альтернативные интерпретации:** разные способы интерпретации данных
- **Рекомендации:** actionable insights и следующие шаги

Функции экспорта:
- Скачать HTML
- Скачать PDF
- Поделиться ссылкой

### 6. Управление приглашениями
**Путь:** `/projects/:projectId/invitations`

Интерфейс для управления приглашениями респондентов:
- Генерация ссылок-приглашений
- Отправка приглашений по email
- Таблица со списком всех приглашений
- Статусы приглашений (отправлено, открыто, отвечено)
- Отслеживание ответов

### 7. Форма опроса (для респондентов)
**Путь:** `/survey/:token`

Интерфейс для прохождения опроса:
- Прогресс-бар с процентом выполнения
- Пошаговая навигация по вопросам
- Типы вопросов:
  - Шкала (1-5 или 1-10)
  - Открытый текст
  - Множественный выбор
  - Аудио-запись (опционально)
- Навигация назад/вперед
- Автосохранение ответов
- Подтверждение завершения

## Основные функции

### AI-интеграция
- **Генерация сценариев:** автоматическое создание опросов на основе сегмента и гипотезы
- **Анализ данных:** AI-генерация отчетов и рекомендаций
- **AI-помощник:** помощь в формулировке гипотез

### Аналитика и отчеты
- Реал-тайм статистика
- Кластерный анализ респондентов
- Выявление трендов и паттернов
- Метрики валидации гипотез

### Управление проектами
- Создание и редактирование проектов
- Версионирование сценариев
- Управление статусами проектов

## Пользовательские потоки

### Создание проекта валидации:
1. Dashboard → Создать проект
2. Шаг 1: Описать целевой сегмент
3. Шаг 2: Сформулировать гипотезу
4. Шаг 3: Проверить/редактировать AI-сценарий
5. Шаг 4: Установить параметры аудитории и цены
6. Проект создан → переход к управлению приглашениями

### Управление проектом:
1. Dashboard → Выбрать проект
2. Детали проекта → просмотр всей информации
3. Управление приглашениями → отправить приглашения
4. Прогресс → отслеживать ответы в реальном времени
5. Отчет → получить анализ и рекомендации

### Прохождение опроса:
1. Респондент получает ссылку-приглашение
2. Открывает ссылку → Форма опроса
3. Отвечает на вопросы пошагово
4. Завершает опрос → подтверждение

## Технические особенности

- Полностью переведено на английский язык
- Адаптивный дизайн (mobile-friendly)
- Реал-тайм обновления
- Современный UI/UX
- Обработка ошибок и состояния загрузки
- Безопасность: токены для доступа к опросам
