# Проверка CRUD Workspace в браузере

**Важно:** не удаляйте уже существующие workspaces. Проверку Delete делайте только для workspace, созданного во время этой проверки.

## Чеклист

1. **Read (список)**
   - Открыта страница http://localhost:5173/workspaces
   - Список workspaces загружается (нет бесконечной загрузки).
   - Существующие workspaces отображаются (иконка или буква + название).

2. **Create**
   - Кнопка «+ New Workspace» (в шапке страницы или в сайдбаре) открывает модальное окно создания.
   - Ввод имени и «Create» — в списке появляется новый workspace.
   - Запомните имя созданного workspace для шага 4.

3. **Update (Edit)**
   - У любого workspace (лучше у только что созданного) нажать Edit (на карточке или в меню ⋮ в сайдбаре).
   - Открывается модальное окно редактирования, меняете имя — «Update».
   - В списке имя обновляется.

4. **Delete (только тестовый workspace)**
   - У workspace, **который вы создали в шаге 2**, нажать Delete.
   - Подтвердить удаление в модальном окне.
   - Workspace исчезает из списка. **Существующие до проверки workspaces не трогать.**

## Сайдбар

- В левом сайдбаре: заголовок «Workspaces», кнопка «New workspace», ссылка «All workspaces», список workspaces.
- У каждого workspace в сайдбаре: клик по ⋮ открывает меню «Edit» / «Delete».
- Клик по названию workspace ведёт на `/workspaces/:id/projects`.

## Если не загружается

- Убедитесь, что backend запущен (например, `npm run dev` в папке `backend`) и доступен по настройкам API (порт 8080 или из env).
- Выполнен вход (логин); без авторизации список workspaces может быть пуст или редирект на логин.
